CHAPTER 02

ติดตั้งและต่อสาย

ต่อสายทุกเส้นให้เรียบร้อยก่อน แล้วเสียบปลั๊กไฟเป็นขั้นตอนสุดท้ายเสมอ

ตัวเลขในภาพ ตรงกับขั้นตอนด้านล่าง

ภาพประกอบการต่อสาย

  1. ภาพ — สาย HDMIต่อจากเครื่องไปที่ทีวีหรือโปรเจกเตอร์
  2. เสียง — USB Sound Cardเสียบ Sound Card เข้าเครื่อง → เสียบสายด้านแจ็คกลม 3.5 มม. ที่ ช่องสีเขียวบน Sound Card → ด้านหัว RCA แดง/ขาว ต่อเข้าชุดเครื่องเสียง
  3. คีย์บอร์ด — สาย USB สีฟ้าเสียบตัวรับสัญญาณเข้ากับสาย USB สีฟ้า แล้วต่อเข้าช่อง USB ช่องไหนก็ได้
  4. อินเทอร์เน็ตต่อสาย LAN หรือ WiFi
  5. ไฟ — เสียบสุดท้ายเสียบ Adapter 5V 2A
🔊
Spark (รุ่นเดิม): มีช่อง Stereo สีขาว/แดงที่ตัวเครื่อง ต่อสาย RCA เข้าชุดเครื่องเสียงได้เลย ไม่ต้องใช้ USB Sound Card · ภาพต่อ HDMI ไปที่ทีวีเหมือนกัน
🧰
ติดตั้งเองได้ หรือให้ทีม MBOX ติดตั้งให้ ค่าบริการติดตั้งครั้งละ 3,000 บาท

ความปลอดภัยทางไฟฟ้า

⚡

ตรวจสายดินก่อนติดตั้ง

ให้ช่างไฟตรวจระบบสายดินของร้าน แรงดันระหว่างสายดินกับนิวทรัลควรใกล้ 0 โวลต์ และเต้ารับต้องมีสายดินต่อลงดินจริง

🔌

เสียบไฟให้ถูกวิธี

MBOX ทีวี แอมป์ มิกเซอร์ เสียบรางปลั๊กเดียวกันในวงจรเดียวกัน ใช้รางกันไฟกระชาก เปลี่ยนทุก 2–3 ปี ห้ามพ่วงหลายชั้น

📺

สาย HDMI

ปิดเครื่องและปิดทีวีทุกครั้งก่อนเสียบหรือถอดสาย HDMI

🛠️

เมื่อมีงานไฟฟ้าในร้าน

ถอดปลั๊กชุดคาราโอเกะทั้งหมด และถอดสาย HDMI ก่อนช่างเริ่มงาน เสียบกลับเมื่อไฟจ่ายนิ่งแล้ว

CHAPTER 03

เปิดเครื่องครั้งแรก

ทำครั้งเดียวตอนติดตั้ง — ใช้แอป LINE บนมือถือ

ลำดับเปิด-ปิดเครื่อง

เปิดใช้งานเครื่อง (Activation)

  1. สแกน QR Code บนจอเปิดเครื่อง แล้วใช้แอป LINE สแกน QR Code ที่ขึ้นบนทีวี
  2. กด Allowอนุญาตสิทธิ์ต่างๆ แล้วจะขึ้น Pop up เปิดใช้งาน
  3. สไลด์ปุ่มเพื่อเปิดสไลด์ปุ่มบน Pop up ในมือถือ
  4. ใส่รหัสเครื่องต่อเน็ต — รหัสส่งไปที่ทีวีอัตโนมัติ
    เครื่องไม่ต่อเน็ต — รหัสเด้งบน Pop up ในมือถือ ให้พิมพ์รหัสผ่านคีย์บอร์ด

  1. กดลูกศร ← → ตัวเลือกจะหมุนไปตามที่กด
  2. เมื่อถึงแอปที่ต้องการ กด Enter เพื่อเข้าแอป

พิมพ์ไทยไม่ได้?

จัดคิวเพลง (สลับลำดับ / ลบ)

⌨️ จากคีย์บอร์ด

  1. กด Tab ให้แถบสีเหลืองย้ายไปที่รายการคิวด้านขวา
  2. กด ↑ ↓ ไปที่เพลงที่ต้องการ
  3. กด Del เพื่อลบ — หรือกด Enter เลือก แล้วกด ↑ ↓ ย้ายลำดับ
  4. กด Enter ยืนยัน (หรือ F9 เล่นเพลงนั้นทันที)

📱 จากแอป MPAD2

  1. ที่หน้าแรกของแอป กดปุ่ม ☰ (ขีด 3 ขีด) มุมขวาบน
  2. เลือก รายการคิวเพลง
  3. กดค้างที่เพลง แล้วปัดซ้าย/ขวาเพื่อลบ หรือลากขึ้น-ลงเพื่อย้ายลำดับ
