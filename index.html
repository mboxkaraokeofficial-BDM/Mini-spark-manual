02ติดตั้งและต่อสาย

ต่อสายทุกเส้นให้เรียบร้อยก่อน แล้ว เสียบปลั๊กไฟเป็นขั้นตอนสุดท้ายเสมอ

  1. ภาพ (HDMI) — ต่อสาย HDMI จากเครื่องไปที่ทีวีหรือโปรเจกเตอร์
  2. เสียง — เสียบ USB Sound Card เข้าเครื่อง แล้วเสียบสายด้านแจ็คกลม 3.5 มม. ที่ ช่องสีเขียวบน Sound Card ส่วนด้านหัว RCA แดง/ขาว ต่อเข้าชุดเครื่องเสียง
  3. คีย์บอร์ด — เสียบตัวรับสัญญาณ Wireless Keyboard เข้ากับ สาย USB สีฟ้า แล้วต่อเข้าช่อง USB ช่องไหนก็ได้ของเครื่อง
  4. อินเทอร์เน็ต — ต่อสาย LAN หรือ WiFi
  5. ไฟ — เสียบ Adapter 5V 2A เป็นขั้นตอนสุดท้าย
🔊 Spark (รุ่นเดิม): มีช่อง Stereo สีขาว/แดงที่ตัวเครื่อง ต่อสาย RCA จากเครื่องเข้าชุดเครื่องเสียงได้เลย ไม่ต้องใช้ USB Sound Card · ภาพต่อ HDMI ไปที่ทีวีเหมือนกัน
🧰 ติดตั้งเองได้ หรือให้ทีม MBOX ติดตั้งให้ ค่าบริการติดตั้งครั้งละ 3,000 บาท

⚡ ตรวจสายดินก่อนติดตั้ง

ก่อนติดตั้งครั้งแรก ให้ช่างไฟตรวจระบบสายดินของร้าน วัดแรงดันระหว่างสายดินกับนิวทรัลควรใกล้ 0 โวลต์ และตรวจว่าเต้ารับที่ใช้มีสายดินต่อลงดินจริง

🔌 เสียบไฟให้ถูกวิธี

เสียบเครื่อง MBOX ทีวี แอมป์ และมิกเซอร์ที่รางปลั๊กเดียวกันในวงจรไฟเดียวกัน ใช้รางปลั๊กกันไฟกระชาก (Surge Protector) เปลี่ยนทุก 2–3 ปี ห้ามต่อรางปลั๊กพ่วงกันหลายชั้น

📺 สาย HDMI

ปิดเครื่องและปิดทีวีทุกครั้งก่อนเสียบหรือถอดสาย HDMI

🛠️ เมื่อมีงานไฟฟ้าในร้าน

ก่อนช่างเริ่มงาน (เดินสายไฟ เปลี่ยนเบรกเกอร์ ตัดไฟทั้งร้าน) ให้ถอดปลั๊กชุดคาราโอเกะทั้งหมด และถอดสาย HDMI ระหว่างเครื่องกับทีวี เสียบกลับเมื่อไฟจ่ายนิ่งแล้ว

03เปิดเครื่องครั้งแรก

ลำดับเปิด: เปิดทีวีก่อน แล้วค่อยเปิดเครื่อง MBOX · ลำดับปิด: ปิด MBOX ก่อน แล้วค่อยปิดทีวี

เปิดใช้งานเครื่อง (Activation)

  1. เปิดเครื่อง แล้วใช้แอป LINE สแกน QR Code บนจอ
  2. กด Allow สิทธิ์ต่างๆ จะขึ้น Pop up เปิดใช้งาน ให้สไลด์ปุ่มเพื่อเปิด
  3. ถ้าเครื่องต่อเน็ต — รหัสจะส่งไปที่ทีวีอัตโนมัติ
    ถ้าเครื่องไม่ต่อเน็ต — รหัสจะเด้งขึ้นบน Pop up ในมือถือ ให้พิมพ์รหัสนั้นผ่านคีย์บอร์ด

เลือกแอปจากหน้า Home

  2. เมื่อถึงแอปที่ต้องการ กด Enter เพื่อเข้าแอป

05ค้นหา · จัดคิว · Playlist

ทำได้ทั้งจากคีย์บอร์ดและแอป MPAD2 บนมือถือ

ค้นหาเพลงด้วย Smart Search

พิมพ์ได้ทั้ง ชื่อเพลง ชื่อศิลปิน และรหัสเพลง ในช่องค้นหาเดียวกัน — กด Tab เพื่อสลับไปโหมดค้นหา พิมพ์ แล้วกด Enter เพื่อเลือก

💡 พิมพ์ภาษาไทยไม่ได้? กดปุ่ม EN (ซ้ายของเลข 1) เพื่อสลับภาษา และใช้ปุ่มคีย์บอร์ดเท่านั้น — การใช้ทัชแพดหรือเมาส์กดพิมพ์เป็นสาเหตุหลักที่เปลี่ยนภาษาไม่ได้

จัดคิวเพลง (สลับลำดับ / ลบ)

⌨️ จากคีย์บอร์ด

  1. กด Tab ให้แถบสีเหลืองย้ายไปที่รายการคิวด้านขวา
  2. กด ↑ ↓ ไปที่เพลงที่ต้องการ
  3. กด Del เพื่อลบ — หรือกด Enter เลือก แล้วกด ↑ ↓ เพื่อย้ายลำดับ
  4. กด Enter ยืนยัน (หรือกด F9 เพื่อเล่นเพลงนั้นทันที)

📱 จากแอป MPAD2

  1. ที่หน้าแรกของแอป กดปุ่ม ☰ (ขีด 3 ขีด) มุมขวาบน
  2. เลือก รายการคิวเพลง
  3. กดค้างที่เพลง แล้วปัดซ้าย/ขวาเพื่อลบ หรือลากขึ้น-ลงเพื่อย้ายลำดับ

สร้าง Playlist (เพลงโปรด)

⌨️ สร้างและเพิ่มเพลงจากคีย์บอร์ด

  1. กด F2 สร้าง Playlist แล้วตั้งชื่อ Folder → Enter
  2. เลือกเพลงที่ชอบ แล้วกด F3
  3. เลือก Folder ที่ต้องการ → Enter

📱 เพิ่มจากแอป MPAD2

  1. กดจุด 3 จุด ⋮ ที่ชื่อเพลง
  2. เลือก เพิ่มใน Favourite

▶️ เล่นเพลงใน Playlist

  1. กด ← → เลื่อนไปเรื่อยๆ จนเจอหมวด รายการเพลงโปรด
  2. กด ↑ ↓ เลือก Folder
  3. เลือกเพลงที่ต้องการ หรือกด Shift+Enter เพื่อเลือกทุกเพลง

ปรับเสียง 3 โหมด

กด F8 เพื่อสลับโหมด คาราโอเกะ / สเตอริโอ / เสียงร้อง ได้ทันที

06ควบคุมผ่านมือถือด้วย MPAD2

MPAD2 ดาวน์โหลดฟรีทั้ง iOS และ Android ใช้ได้กับเครื่อง MBOX ทุกรุ่น

สแกนเพื่อดาวน์โหลดแอป MPAD2
หรือค้นหา “Mpad2” ใน App Store / Google Play

เชื่อมต่อแอปกับเครื่อง

  1. ต่อมือถือเข้าเครือข่ายตามตารางด้านล่าง
  2. เข้าเมนู Karaoke บนเครื่อง แล้วกด F1 (วิธีการใช้งาน / เชื่อมต่อ) จอจะแสดง QR Code
  3. เปิดแอป MPAD2 แล้วสแกน QR ฝั่งขวามือ
  4. เชื่อมต่อเสร็จ เลือกเพลง ปรับเสียง หยุด เล่น หรือข้ามเพลงจากมือถือได้ทันที
